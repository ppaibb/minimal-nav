AI 编程助手接入指南

🔥 准备工作与注意事项：
1. 独立专属 Key：每个人使用独立的专属 API Key，请勿混用或共享。开通权限或获取 Key 请在飞书联系 @闫东。
2. 分组说明：当前 Key 区分 Claude 与 Codex 独立路由分组，如需跨组使用请联系管理员调整。

将 Claude Code 的默认请求地址替换为 724AI 中转站（api.724ai.org），直连稳定无需代理。

1. 安装 Claude Code

确保已安装 Node.js 环境（建议 Node 18+）。根据网络环境选择一种安装方式：

方式一：npm 安装（推荐，无需代理）

npm install -g @anthropic-ai/claude-code

安装完成后，即可在终端使用 claude 命令。VS Code 用户可在插件市场搜索安装「Claude Code for VS Code」。

方式二：官方脚本安装（需代理）

curl -fsSL https://claude.ai/install.sh | bash
若无代理直连会返回网页错误页，导致 bash 报 syntax error 乱码。遇到报错请改用方式一（npm 安装）。

2. 配置 724AI 接入

编辑配置文件 ~/.claude/settings.json（Windows 对应 C:\Users\用户名\.claude\settings.json）：

{
  "env": {
    "ANTHROPIC_API_KEY": "sk-xxxxxxxxxxxxxxxx",
    "ANTHROPIC_BASE_URL": "https://api.724ai.org",
    "CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS": "1"
  }
}
注意：ANTHROPIC_BASE_URL 必须填写 https://api.724ai.org，末尾严禁加斜杠 /。请将 API_KEY 替换为您自己的专属 Key。

3. 免登录配置（跳过官方鉴权）

为了跳过强制的官方网页登录，在 ~/.claude.json 中添加跳过标识：

{
  "hasCompletedOnboarding": true
}

4. 开始使用与模型推荐

在项目目录下输入命令启动：

claude
启动后 Claude 若提示是否使用自定义 Key，必须输入 yes。如果选错，可删除 ~/.claude.json 重新配置。

常用模型说明

  • claude-sonnet-5：日常主力编码推荐（响应快、成本适中）
  • claude-fable-5：复杂攻坚任务模型

指定模型单行启动：

claude --model claude-sonnet-5

Codex 提供桌面 App（新手首选）和 CLI 命令行两种使用方式，共享同一套中转配置。

1. 安装 Codex

方式 A：桌面客户端 App（图形界面，新手首选）

前往 Codex 官方页面 下载对应平台版本：

  • Windows：点击下载入口，跳转至 Microsoft Store 安装。
  • macOS（Apple Silicon）：下载 Apple Silicon 版本（M1/M2/M3/M4）。
  • macOS（Intel）：下载 Intel 版本（Intel Core i5/i7/i9）。

安装完成后，打开 App → 选择本地项目目录 → 开始提问即可。

方式 B：CLI 命令行工具

macOS / Linux

先确认已安装 Node.js：

node -v
npm -v

通过 npm 安装（推荐）：

npm install -g @openai/codex

或通过 Homebrew 安装（已习惯 brew 的用户）：

brew install --cask codex

Windows

安装 Node.js 后，打开 PowerShell 执行：

npm install -g @openai/codex

验证安装：

codex --version

2. 核心配置文件

新建或编辑 ~/.codex/config.toml（Windows 对应 C:\Users\用户名\.codex\config.toml）：

model_provider = "724AI"
model_reasoning_effort = "xhigh"
disable_response_storage = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.724AI]
name = "724AI"
wire_api = "responses"
base_url = "https://api.724ai.org/v1"
requires_openai_auth = true
supports_websockets = false
注意：base_url 必须以 /v1 结尾，即 https://api.724ai.org/v1。

在同一目录新建 ~/.codex/auth.json，写入专属 Key：

{
  "OPENAI_API_KEY": "sk-xxxxxxxxxxxxxxx"
}

3. 启动

进入项目目录后启动：

codex

常用模型说明

  • gpt-5.6-sol：复杂攻坚任务模型（推理能力强，消耗较大）
  • gpt-5.6-luna：日常主力编码推荐（响应快、成本适中）

启动时指定模型：

codex --model gpt-5.6-sol

已进入会话后，通过斜杠命令切换模型：

/model gpt-5.6-luna

WorkBuddy 支持兼容 OpenAI 协议的自定义模型，直接使用 724AI 通用接口地址即可。

1. 下载与安装

前往官网获取最新客户端：https://www.workbuddy.cn/

安装后打开客户端，点击左下角头像 → 设置 → 模型，点击「添加模型」。

2. 填写模型配置

配置项 推荐填写值 / 说明
提供商 选择 自定义 / Custom
接口地址 https://api.724ai.org/v1
API Key 填写从 724AI 获取的专属密钥（sk-...）
模型名称 填写可用模型名称，例如 gpt-5.6-sol
高级配置 建议勾选「工具调用」与「图片输入」

保存配置后，在聊天窗口顶部的模型下拉菜单中切换至您添加的自定义模型即可正常使用。

常用模型说明

  • gpt-5.6-sol：复杂攻坚任务模型（推理能力强，消耗较大）
  • gpt-5.6-luna：日常主力编码推荐（响应快、成本适中）

在模型名称一栏填写对应模型名即可使用。
